## Decisions that reconcile the examples

- Use the **detailed** presets. The additional example paths (`fx_rates.yml`, `global_auth_helper.rb`, `spec_helper.rb`, and the FX settlement migration) remain available as manual edits.
- The YAML/JSON scenario has **25 runtime hits total**, including the three mandatory specs. Masks overlap; they are ORed, not summed.
- A genuinely **new** migration has no baseline reads. In addition to two always-mandatory linters and one previous failure, seven directory-specific linters watch `db/migrations/*.rb`. They contribute guard bits, not imaginary bitmap hits on a new file.
- Root-scope fallback and the hypothetical lazy-load preview are different operations. Refactoring `root_boot_helper.rb` must not deactivate another root preload.
- Show computed, rounded percentages and measured union latency, not hard-coded example numbers. A timer below clock resolution should say so. A recorded _demo_ shadow run is not a live `cleave --verify`.

## UI design reference

Used [Stageshow's Linear composition, craft and review notes](https://github.com/benjitaylor/skills/tree/299140fafd08df55a9c234e610c3f64af3f45531/stageshow). The focal action is a real inventory edit; the payoff is its attributed selection, not a staged cursor. Use full-height matte docks, one restrained set of icons, aligned telemetry, solid/dashed edge semantics, an actual compact layout, and inspect the result at desktop and phone widths. No copied animation kit, filler rows, decorative gradients, card outlines or shadows.
